# Steel City Safety Index

## Project Overview
This project analyzes Pittsburgh neighborhoods using
crime statistics and park acreage to evaluate neighborhood
safety and quality of life.

## Datasets Used
- Crime Dataset: https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard
- Pittsburgh Parks Dataset: https://data.wprdc.org/dataset/parks1
- PLI Dataset: https://data.wprdc.org/dataset/pittsburgh-pli-violations-report

## Project Files
- SteelCitySafetyIndex.ipynb – Crime dataset-based notebook focusing on the rankings of the neighborhoods solely on the crime ranking metric.
- parks_ranking (2).ipynb – Parks dataset-based notebook focusing on the rankings of the neighborhoods solely on the park ranking metric.
- PLI_Ranking.ipynb - PLI dataset-based notebook focusing on the rankings of neighborhoods solely on the PLI ranking metric.
- Metric (2).ipynb - All 3 datasets above are taken into account to find the best neighborhood in Pittsburgh in a 1-10 metric. 
## Methodology
We use Python and data analysis techniques to examine
crime rates and park acreage across Pittsburgh neighborhoods.
